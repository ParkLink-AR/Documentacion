\section{Trabajos futuros}

Como trabajo futuro, y a modo de ejemplo para el informe final, se plantea ampliar ParkLink con sensores IoT para detectar la ocupación de las cocheras, modelos de predicción de demanda y mecanismos de integración con operadores de estacionamientos. Estas funcionalidades no forman parte del MVP propuesto, ya que requieren infraestructura, datos históricos y validaciones adicionales que exceden el alcance inicial.
