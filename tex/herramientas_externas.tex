\section{Herramientas externas utilizadas}

Como ejemplo de esta sección para el anteproyecto, ParkLink prevé utilizar herramientas externas para resolver necesidades específicas del sistema sin desarrollar desde cero capacidades de cartografía, autenticación y pagos. Entre ellas se consideran una API de mapas para la visualización georreferenciada, un proveedor de autenticación y una pasarela de pagos digitales. La selección definitiva se realizará según criterios de disponibilidad, costos, documentación, límites de uso y compatibilidad con la arquitectura del MVP.
